I run the Global Supply Chain Index, a free public website that tracks supply chain conditions: https://gscindex.com

The site uses the Bank of Japan Time-Series Data Search API for two series from the Corporate Goods Price Index (import price index, contract-currency basis):

- PRCG20_2500850005 (MOS memory integrated circuits)
- PRCG20_2500850004 (MOS logic integrated circuits)
